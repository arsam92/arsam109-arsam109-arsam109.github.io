# ARlun

ARlun is a game-focused programming language and runtime for games, AI, animation, networking, and tools.

## Architecture

ARlun Code -> Lexer -> Parser -> AST -> Semantic Checker -> IR -> Runtime -> Game Engine

## Systems
- Type system and compiler pipeline
- Scenes, assets, renderer, physics, audio, input
- Materials, lighting and real shadows
- Frame-by-frame animation editor with 3D viewport and rigging
- Goal-driven multi-agent AI with perception, memory, planning, communication, voting and learning
- Optional high-level AI/team brain without exposing hidden game state
- Multiplayer networking with server authority, RPC, replication and prediction
- Debugger and AI inspector

## Status
Early prototype. The repository is being built incrementally.
